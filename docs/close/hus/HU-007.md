# HU-007 — Configuración SonarQube por proyecto y tarjeta con semáforo en dashboard

**Como** usuario interno de monitoreo técnico  
**Quiero** ver la información de SonarQube (quality gate y semáforo) en el dashboard del proyecto seleccionado  
**Para** evaluar la salud de calidad sin tener que entrar a Sonar

---

## Dependencias

- Requiere: HU-001 (estructura base del proyecto)
- Requiere: HU-002 (Tailwind y theme base en modo claro)
- Requiere: HU-004 (cascarón UI del dashboard)
- Requiere configuración previa: variables de entorno de SonarQube (ver sección Contexto)

---

## Contexto / Notas

- Tarjeta de integración SonarQube en el dashboard de un proyecto seleccionado desde `/project-selector`.
- Configuración por variables de entorno: `SONAR_BASE_URL`, `SONAR_TOKEN`, `SONAR_PROJECT_KEY_MAP`.
- Si Sonar responde mal o no está configurado, la tarjeta debe mostrarse igual con estado degradado; no debe romperse el dashboard.
- El semáforo (verde/amarillo/rojo) representa el Quality Gate; debe ser entendible de un vistazo.
- Los datos mostrados deben estar claramente asociados al proyecto seleccionado para evitar confusión.
- Arquitectura: Domain, Infrastructure y Presentation. Repository/Use Case para Sonar.
- Validación QA: `docs/close/hus/HU-004-taller/equipo-1-sonarqube-validacion-qa.md`.

---

## Variables de entorno

Agregar en `narnia/.env`:

```env
SONAR_BASE_URL=https://sonarcloud.io
SONAR_TOKEN=<SONAR_TOKEN>
SONAR_PROJECT_KEY_MAP={"afiliaciones":"ComfandiTD_sucursal-afiliaciones"}
```

## Criterios de aceptación (Given / When / Then)

### 1) Ver información de Sonar en el dashboard

- **Dado** un proyecto configurado con SonarQube
- **Cuando** abro el dashboard del proyecto seleccionado
- **Entonces** se muestra la tarjeta de SonarQube con semáforo y/o Quality Gate sin tener que entrar a Sonar

### 2) Degradación ante fallo de Sonar

- **Dado** que Sonar no responde o responde con error
- **Cuando** abro el dashboard
- **Entonces** la tarjeta de Sonar se muestra igual, con estado degradado (ej. "sin dato" o "desconocido"), y el resto del dashboard no se rompe

### 3) Semáforo entendible

- **Dado** la tarjeta de SonarQube
- **Cuando** se visualiza el estado del Quality Gate
- **Entonces** el semáforo es claramente interpretable (verde / amarillo / rojo u equivalente) usando tokens del tema

### 4) Identificación del proyecto

- **Dado** la tarjeta de SonarQube
- **Cuando** se visualizan los datos
- **Entonces** se identifica claramente a qué proyecto pertenecen para no generar confusión
