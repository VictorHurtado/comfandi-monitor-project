# HU-003 — Crear cascarón UI: Selector de Proyectos (sin funcionalidad)

**Como** usuario interno de la plataforma  
**Quiero** visualizar la pantalla de selector de proyectos con estructura y estilos base  
**Para** que los equipos desarrollen funcionalidades sobre un cascarón UI consistente

---

## Dependencias

- Requiere: HU-001 (estructura base del proyecto)
- Requiere: HU-002 (Tailwind y theme base en modo claro)
- Requiere configuración previa: rutas/paginas base en `narnia`

---

## Contexto / Notas

- Esta HU implementa solo la capa de Presentation (layout y componentes visuales).
- No debe incluir integraciones reales, consumo de APIs ni logica de negocio.
- Debe tomar como referencia directa el diseño provisto por `code.html` y `screen.png`.
- El resultado esperado es un cascarón navegable visualmente, listo para iteraciones funcionales.
- **Tema obligatorio: claro** (sin dark mode).

## Alcance

Incluye:
- Pantalla de selector de proyectos en tema claro.
- Top navigation, hero, controles visuales y grid de tarjetas.
- Estados visuales de tarjetas (saludable, atencion, critico) como estilos estaticos.

## Criterios de aceptación (Given / When / Then)

### 1) Render de estructura principal

- **Dado** el proyecto ejecutandose en local
- **Cuando** se navega a la ruta del selector de proyectos
- **Entonces** se visualizan header, hero, filtros, grid de cards y footer segun el diseño de referencia

### 2) Cascarón sin funcionalidad

- **Dado** los controles de busqueda/filtros/botones
- **Cuando** el usuario interactua
- **Entonces** no hay llamadas a APIs ni logica de negocio, solo comportamiento visual basico permitido

### 3) Consistencia de tema claro

- **Dado** la implementacion de la pantalla
- **Cuando** se revisan clases y tokens
- **Entonces** usa theme claro y tokens definidos, sin dependencias de dark mode

### Arquitectura
- Solo capa Presentation.
