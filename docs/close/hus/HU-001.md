# HU-001 — Inicializar proyecto base Narnia (Next.js + BFF)

**Como** equipo de desarrollo de la plataforma de reportes  
**Quiero** inicializar un proyecto base en Next.js con estructura de Clean Architecture y backend server-side (BFF)  
**Para** habilitar trabajo paralelo de varios equipos con contratos claros, seguridad centralizada y base tecnica estandar

---

## Dependencias

- Requiere: ninguna HU previa (HU fundacional)
- Requiere: TC-002 (tema Tailwind `brand-*`) para la configuracion inicial de UI
- Requiere configuracion previa: Keycloak (realm/client), variables de entorno, IoC, convenciones de lint/format, Jest

---

## Contexto / Notas

- `narnia` sera el frontend principal con backend server-side en Next.js (BFF).
- `proteo` es una API externa independiente (PQRS) y no debe ser consumida directamente desde componentes UI.
- Integraciones externas (Sonar, GitHub, Sentry, Proteo) se consumen desde Infrastructure mediante contratos del Domain.
- Se debe seguir estrictamente `docs/close/01_arquitectura.md`:
  - Presentation consume Use Cases via IoC.
  - Domain no depende de frameworks.
  - Infrastructure implementa contratos y maneja integraciones.
- Esta HU define estructura base y wiring inicial; no implementa logica de negocio de reportes.

## Reglas técnicas

### Arquitectura
- Presentation solo consume UseCases via IoC (no importa repositorios concretos).
- Domain no importa React/Next/Tailwind/Inversify/Axios.
- Infrastructure contiene implementaciones, adapters y wiring IoC.
- Los contratos de integracion externa viven en Domain; adapters concretos viven en Infrastructure.

### UI (si aplica)
- UI con **Tailwind CSS**.
- **Usar SIEMPRE los tokens `brand-*`** del tema en `tailwind.config.ts`.
- Tipografia: `font-outfit`.
- No agregar librerias de estilos adicionales sin HU especifica.

### Seguridad / Integraciones
- Keycloak como proveedor de autenticacion/autorizacion.
- Secretos y tokens solo en entorno server-side.
- `proteo` se consume unicamente desde backend server-side de Next.js.
- Sonar/GitHub/Sentry se consumen via adapters de Infrastructure, no desde UI.

### Dependencias / Paquetes
- No agregar dependencias nuevas salvo las necesarias para bootstrap aprobado (Next.js, Tailwind, IoC, testing, auth).
- Si aparece error 403/conectividad:
  1) Detenerse
  2) Pedir dominios requeridos
  3) Explicar por que se requieren
  4) No continuar
