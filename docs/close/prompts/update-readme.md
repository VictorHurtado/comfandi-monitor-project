# Prompt: Actualizar README del proyecto

> Usar este prompt después de implementar una nueva HU para mantener el README actualizado.

```
Actualiza el readme.md del proyecto. NO reescribas lo existente.
Lee los archivos docs/documentation/PR_<ID-HU>.md más recientes que aún no estén
reflejados en el README. Agrega las nuevas funcionalidades al System Map e Historial,
actualiza integraciones si hay nuevas, y ajusta la sección de arquitectura
solo si hubo cambios estructurales. Mantén el formato existente.
```
